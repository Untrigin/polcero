## PHOTONIC AI COMPUTING

**Key concept:** Optical matrix multiplication using Mach-Zehnder interferometer meshes performs the core neural network operation (GEMM) in a single light pass — sub-nanosecond vs. microsecond for electronic GPUs.

**Market:** $1.8B in 2025 → $14.6B by 2034 (CAGR 26.3%). 52 companies tracked globally (2026).

**Architecture:** Hybrid photonic-electronic — optical for matrix math + electronic for nonlinear activations.

**Key companies:**
- **Lightmatter (USA):** Passage M1000 (114 Tbps photonic interposer); $400M Series D 2025; first to run transformers + CNNs without modification
- **Q.ANT (Germany):** ~50× advantage vs NVIDIA GPU in matrix-vector benchmarks (LRZ validated)
- **Neurophos (USA):** Claims 10× NVIDIA Vera Rubin NVL72 in FP4/INT4; 1,000×1,000 optical matrix chip demonstrated
- **Celestial AI → Marvell:** Acquired for $3.25B Dec 2025
