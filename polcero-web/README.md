# POLCERO — corporate site (Astro)

SEO-first, static-rendered marketing site for **POLCERO** — autonomous robots for industry and
agriculture. Built with **Astro + TypeScript + Tailwind CSS v4**. NEURA-style dark-editorial layout,
single orange accent (`#FF6A1A`).

- **Output:** 100% static HTML (`output: 'static'`), zero JS by default.
- **Interactivity:** lightweight vanilla-TS enhancement only (header, tabs, hover-list, reveal/parallax).
  Homepage ships **~1.4 KB gzipped JS** (well under the 60 KB budget). No React/framework on the client.
- **i18n:** Polish at `/` (primary), English at `/en/`. Reciprocal `hreflang` + `x-default` on every page.
- **Rendering:** pages are prerendered; only the contact form endpoint (`/api/contact`) runs on the server
  (`@astrojs/node`, standalone), so the site now runs as a Node process rather than pure static files.

## Contact form (SMTP)

The contact form posts to `src/pages/api/contact.ts`, which sends mail via **nodemailer** using SMTP.
Configure the SMTP vars (see `.env.example`) in the server environment. It includes a honeypot field and
relies on Astro's built-in CSRF origin check.

**Deploy on the Node server (Hetzner):**

```bash
npm ci
npm run build
# run the standalone server (serves the static pages AND /api/contact):
HOST=0.0.0.0 PORT=4321 node --env-file=.env ./dist/server/entry.mjs
```

Put a real `.env` (from `.env.example`, gitignored) next to the app, or set the vars via systemd/pm2.
Reverse-proxy nginx → `127.0.0.1:4321`. (Node 20+ is required for `--env-file`.)

## Structure

```
src/
├─ components/           # SplitHeading, BoxArrowLink, MediaFrame, ProductCard, SiteHeader/Footer…
│  └─ pages/             # page templates (ProductDetail, IndustryDetail, NewsIndex/Article, About, Contact…)
├─ data/content.ts       # ALL copy + product/industry data, keyed by locale (pl/en) — single source
├─ layouts/Layout.astro  # shell: <head>/SEO, header, footer, motion script
├─ content/news/{pl,en}/ # news posts (content collection)
├─ scripts/motion.ts     # reveal + parallax (vanilla, reduced-motion aware)
├─ lib/i18n.ts           # locale helpers (localizedPath, alternatePath, hreflang)
└─ pages/                # routes (PL at root, EN under /en/)
```

## Media — swapping in real photography

Placeholders live in `public/media/` (brand-gradient tiles with dimension labels), generated by
`scripts/gen-placeholders.mjs`. **Replace each file with real photography at the same filename and
aspect ratio** (dimensions are fixed to keep CLS at zero):

| File | Size / ratio | Used by |
| :-- | :-- | :-- |
| `hero.webp` | 2560×1440 (16:9) | Homepage hero |
| `product-01..04.webp` | 1024×1024 (1:1) | Product cards / tiles / mega-menu |
| `tab-industry.webp` | 1600×1200 (4:3) | Tabs — Industry, `branze/przemysl` |
| `tab-services.webp` | 1600×1200 (4:3) | Tabs — Agriculture, `branze/rolnictwo` |
| `tab-home.webp` | 1600×1200 (4:3) | Tabs — Logistics, `branze/logistyka` |
| `mission.webp` | 2000×1200 (5:3) | Mission band, About, news covers |
| `hero-bg.mp4` / `.webm` + `hero-bg-poster.jpg` | 1280×720, ~8s | Full-screen hero video (desktop) |
| `hero-mobile.webp` | 1080×1440 | Full-screen hero image (mobile fallback) |
| `part-*.webp` | varies | Components cut from `robot_parts.png` (construction section) |
| `og/default.png` | 1200×630 | Default social share image |

The full-screen hero (`scripts/gen-hero-bg.sh`) is decorative and SEO-safe: **desktop** loads the looping muted video
(sources injected by `motion.ts` only when the viewport is ≥768px and motion is allowed, and it pauses off-screen);
**mobile** downloads no video at all and shows `hero-mobile.webp`. The H1 text is always in the DOM. The original
POLCERO logo lives at `public/polcero_white.svg` (white, for the dark UI). Component images for the "Budowa modułowa"
section are cut from `../photos/robot_parts.png` — see the `part-*` crop coordinates in git history / regenerate manually.

Source photography for the content phase is in the repo root `../photos/` (humanoid robots + drone).
Product tiles use `object-contain` + `mix-blend-mode: multiply` on a light panel — supply
**cut-out / transparent-background** product shots for best results.

> Prefer AVIF+WebP with responsive `srcset` once real images land — move them into `src/assets/` and
> render via `astro:assets` (`<Image>`) to get automatic optimization. Placeholders stay in `public/`.
